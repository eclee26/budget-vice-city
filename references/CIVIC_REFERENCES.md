# Civic exterior references

The game keeps the requested display names. The FD/FB target Asian-market sedans; the 1997 car follows the pre-facelift EK4/Ferio sedan silhouette. Regional trim names differ: Japanese 1997 EK4 sedans were catalogued as Ferio Si; SiR also appears on hatchbacks. This reference choice preserves the sedan body requested/implemented in this project.

## Implementation and limits

The procedural reconstruction targets recognizable exterior shape: rounded body sections, wheel openings, roof/glass curvature, separate side windows, generation-specific grille/headlamp/rear-lamp outlines, trim, mirrors and wheels. It is a reference-informed approximation, not a dimensionally certified 1:1 scan or a manufacturer CAD asset. Physics stays independent of these cosmetic meshes.

Reference photographs remain on their original sites and are not bundled as game textures. The search tool could identify/open reference pages; direct downloads from external photo hosts were denied by the execution environment's network policy. No photo textures or externally sourced model meshes are shipped.
